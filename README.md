# laiqo-media

Images et vidéos du site [laiqo.fr](https://laiqo.fr), servies par GitHub Pages
depuis `https://laiqo.github.io/laiqo-media/media/<empreinte>.<ext>`.

Les fichiers sont nommés d'après l'empreinte SHA-256 de leur contenu : deux
envois du même fichier ne créent qu'un exemplaire, et l'adresse ne change jamais.

Dépôt public parce que GitHub Pages n'existe pas sur un dépôt privé en compte
gratuit. Il ne contient que des médias déjà visibles sur le site.

Ajouts : depuis l'admin du site (jusqu'à 20 Mo), ou `npm run media:push` depuis
le dépôt du site (jusqu'à 100 Mo).
